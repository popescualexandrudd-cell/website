# Nivelurile 1.0–7.0, în cuvinte (§6.3, LG-032)

> Creat în Etapa 2 (27.09.2026). Scala 1.0–7.0 este cea folosită larg în padelul amator. Descrierile sunt un ghid pentru chestionarul de nivel (§6.4) și pentru antrenorul care îl validează; **nivelul din ligă se calculează din rezultate**, nu din descriere. Textele pot fi ajustate de proprietar și de antrenori (DE_CONFIRMAT).

| Nivel | Pe scurt | Cum arată jocul |
|---|---|---|
| **1.0–1.5** | Începător absolut | Primele ore de padel. Loviturile de bază (forehand, rever) ies uneori; mingea care vine din perete e încă o surpriză. Serviciul intră cu greu. |
| **1.5–2.0** | Începător | Schimburi scurte cu ritm lent. Începe să lase mingea să treacă de perete, dar nu o controlează. Nu are încă o poziție clară pe teren. |
| **2.0–2.5** | Începător avansat | Controlează loviturile de bază la viteză mică. Știe regulile și locul lui pe teren (la fund sau la fileu). Serviciu sigur, fără efect. |
| **2.5–3.0** | Intermediar de început | Schimburi mai lungi. Apare voleul și primele lovituri din perete, încă nesigure. Începe să urce la fileu împreună cu partenerul. |
| **3.0–3.5** | Intermediar | Joacă din perete în majoritatea situațiilor, cu direcție. Lob defensiv folosit conștient. Voleu stabil la viteză medie. |
| **3.5–4.0** | Intermediar bun | Controlează ritmul; alege între lob, minge lentă și atac. Bandeja apare în joc. Comunică și se mișcă în tandem cu partenerul. |
| **4.0–4.5** | Intermediar avansat | Bandeja și víbora sigure; ieșiri bune din colț (perete dublu). Construiește punctul cu intenție; puține greșeli neforțate. |
| **4.5–5.0** | Avansat | Varietate de efecte și viteze; smash spre ieșire (x3 / x4) în situațiile ușoare. Citește jocul adversarului și anticipează. |
| **5.0–5.5** | Avansat puternic | Joc complet, fără puncte slabe evidente. Presiune constantă la fileu; apărare solidă din fund. Joacă turnee amatoare cu rezultate. |
| **5.5–6.0** | Competiție | Nivel de turnee de club și regionale. Tactică elaborată, lovituri decisive sigure, fizic bun pe meciuri lungi. |
| **6.0–7.0** | Competiție înaltă / semiprofesionist | Rezultate în circuite naționale; aproape de nivelul jucătorilor clasați. La 7.0: nivel profesionist. |

## Legătura cu rangurile din ligă
Rangul nu este nivelul: rangul se câștigă cu LP, meci cu meci, în fiecare sezon. Formula LP (§6.6) împinge însă, în timp, fiecare jucător spre rangul care corespunde nivelului lui. Cu valorile calibrate ([simulari/CALIBRARE.md](simulari/CALIBRARE.md)), corespondența orientativă este:

| Nivel | Rang spre care tinde |
|---|---|
| sub 2.2 | Bronz |
| 2.2–3.1 | Argint |
| 3.1–4.1 | Aur |
| 4.1–5.0 | Platină |
| 5.0–5.9 | Diamant |
| peste 5.9 | Maestru |

Corespondența se recalibrează după „Sezonul 0 – Calibrare”, cu datele reale ale clubului.
