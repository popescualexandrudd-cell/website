# Componente UI partajate (React)

> **Stare:** neînceput (schelet creat în Etapa 0, 26.09.2026). **Se construiește în Etapa:** 1B și următoarele.

## Ce face

Componentele comune (butoane, formulare, carduri de clasament, afișaje de rang, tastatura tactilă a chioșcului etc.), accesibile (WCAG 2.2 AA), construite doar pe design tokens.
