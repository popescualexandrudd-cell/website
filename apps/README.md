# Aplicații

Fiecare aplicație are folderul ei și poate fi rulată și publicată separat, pe subdomeniul ei (§4.4, §4.6).

- [`admin/`](admin/) — Panoul de admin (React + Vite)
- [`backend/`](backend/) — Backend central (Django)
- [`cafe-display/`](cafe-display/) — Afișajul cafenelei
- [`court-screens/`](court-screens/) — Ecranele de la terenuri și din lobby / cafenea / mezanin
- [`kiosk-league/`](kiosk-league/) — Chioșcul de Ligă (aparatul 1)
- [`kiosk-payments/`](kiosk-payments/) — Chioșcul de Plăți (aparatul 2)
- [`web/`](web/) — Website public + contul clientului (Next.js, PWA)
